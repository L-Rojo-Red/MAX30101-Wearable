# MAX30101 Wearable

Open-source hardware and software resources for a low-cost wearable cardiac monitoring prototype based on photoplethysmography (PPG).

## Repository Contents

- **Hardware:** PCB manufacturing files (Gerber), bill of materials (BOM), and enclosure models.
- **Firmware:** ESP32 firmware.

## Hardware

The prototype uses an ESP32-C6-MINI-1 microcontroller and a MAX30101 optical sensor for PPG signal acquisition.

## Software

The repository provides the firmware developed for the experimental prototype.

## Limitations

This prototype is intended for research and experimental purposes. It is not a certified medical device and must not be used for clinical diagnosis or treatment.

## Reproducibility

The shared files are intended to support hardware fabrication, software implementation, and further research.
